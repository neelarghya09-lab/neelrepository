# ✊✋✌️ Rock–Paper–Scissors Game

A fun and interactive **Rock–Paper–Scissors web app** built with **HTML, CSS, and JavaScript**.  
Play against the computer, track scores, and enjoy a clean mobile‑style interface.

---

## 🚀 Features
- 🎮 Player vs Computer mode
- 🔄 Randomized computer choices
- 🏆 Real‑time score tracking
- 📱 Responsive mobile‑style design
- ✨ Simple animations and clean UI
